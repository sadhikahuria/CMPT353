1. Not really, no. The residual histogram is not symmetric like a normal distribution should be. It is left-skewed with a long tail of negative residuals, plus a few outliers. So the normality assumption behind the OLS p-value does not hold very well, and I would not take the exact p-value too literally. That said, the p-value is extremely small, far below 0.05, and there are over 2000 data points. So even with the non-normal residuals, it is still reasonable to conclude that the ratings are increasing over time. I just would not rely too heavily on the exact p-value itself.

2. Yes, I think so. With the identity transition, the Kalman filter mostly assumes that the next state is similar to the current state, so it mainly smooths the noisy observations. Once we replace the temperature row of the transition matrix with the regression coefficients, the filter uses cpu_percent, fan_rpm, sys_load_1, and cpu_freq to help predict the next temperature. That gives the filter more useful information about what is driving temperature changes, so the smoothed line follows the real temperature changes better, especially during faster rises and drops. It still does not catch every single spike, but that is expected because the filter is trying to estimate the underlying signal rather than follow every noisy observation.
