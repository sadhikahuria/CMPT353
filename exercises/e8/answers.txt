Honestly kNN (LAB) and RF (HSV) were basically tied for the best model, it kept flipping which one "won" depending on the run, but both were clearly ahead of Bayes, usually around 0.75-0.77 vs Bayes around 0.6-0.66. I think Bayes does worse because GaussianNB assumes the features are independent and roughly normal within each class, which isn't really true for colour data, while kNN and RF don't make that assumption so they can fit weirder shaped boundaries. For LAB vs HSV, LAB distances are supposed to match how different colours actually look, which probably helps kNN since it's literally just measuring distances. HSV probably helps RF because hue is basically the colour packed into one number, so RF can just threshold on it a couple times instead of combining all 3 RGB channels.

Yeah I think the mistakes are pretty reasonable, almost every wrong prediction was between cities that are close together and climate-similar, like Seattle/Portland/Victoria/Vancouver, Regina/Saskatoon/Winnipeg/Edmonton, and Montreal/Ottawa/Toronto/London, plus Atlanta and Raleigh Durham/New Orleans. This lines up with the cluster plot too, the same groups end up in the same clusters, so it's not like the model is randomly wrong, it's confusing cities that genuinely do have similar weather. For extra features, I think monthly averages hide a lot of the actual differences, two cities could have the same average temp but totally different day to day patterns, so something like variability within the month would probably help, and stuff not in the data at all like humidity, wind, or cloud cover could help too, Seattle vs Portland especially might just come down to fog/cloud cover which we don't have.
